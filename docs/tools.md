## Session

### `session_status` — Login status

*read only*

Whether this server has a Stockbit session (needed by every tool) and a trading session (needed by the account_* tools), with their expiry. Never returns the tokens. If a session is missing, tell the user to run `stockbit-mcp login` (or `stockbit-mcp login --trading`) in a terminal.

## Orders (real money: two confirmation popups, needs the trading session)

### `order_buy` — Buy a stock (limit order)

*asks for confirmation / permission*

Places a real BUY order on the user's Stockbit account with real money: a limit order, good for today, on the regular board (RG). Before anything is sent the tool checks the stock (tradable, not suspended, sharia for a syariah account), the price (IDX tick, inside today's ARB–ARA band) and the trading balance, then shows the user two confirmation popups in a row. The order goes out only if they accept both; clients without popups (MCP elicitation) cannot place orders.

| Input | Required | Description |
|---|---|---|
| `symbol` | yes | IDX ticker such as BBCA or TLKM (no exchange prefix). |
| `lot` | yes | Lots to buy (1 lot = 100 shares), at most 50.000 per order. |
| `price` | yes | Limit price per share in IDR, on the IDX tick grid (steps of 1 below 200, 2 below 500, 5 below 2,000, 10 below 5,000, 25 from 5,000). |

Endpoint: `POST carina /order/v2/buy`

The order goes out only if they accept both; clients without popups (MCP elicitation) cannot place orders.

| Input | Required | Description |

## Whole catalog

### `api_catalog` — Search the Stockbit endpoint catalog

*read only*

Lists Stockbit endpoints the desktop app uses, with their parameters, allowed values and what they return. Use it to find an endpoint for api_get when no dedicated tool fits, or to look up the exact enum values a dedicated tool accepts. Filters combine; with none, it lists groups and counts only.

| Input | Required | Description |
|---|---|---|
| `query` |  | Words matched against id, path, group and feature (all must match), e.g. "broker summary". |
| `group` |  | Exact group, e.g. market, emitten, insider, screener, trading. |
| `include_writes` |  | Also list endpoints that change something (for reference; api_get only reads). |
| `limit` |  | Max endpoints to return, default 20. |

### `api_get` — Call any Stockbit read endpoint

*read only*

Calls one GET endpoint from api_catalog by its id. Path parameters fill the {placeholders}; query parameters use the names api_catalog lists (for documented endpoints, unknown names are refused). Returns Stockbit's data field. Prefer a dedicated tool when one exists.

| Input | Required | Description |
|---|---|---|
| `endpoint_id` | yes | The id from api_catalog, e.g. get_broker_summary_v2. |
| `path_params` |  | Values for the {placeholders} in the path. |
| `query` |  | Query parameters; a list sends the key once per item. |
